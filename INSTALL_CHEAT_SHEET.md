# ⚡ INSTALL CHEAT SHEET

## 🚀 Install & Use in 3 Steps

### STEP 1: Install Plugin
```
WordPress Admin → Plugins → Add New → Upload Plugin
Choose: scheda-clienti-plugin.zip
Install Now → Activate
```

### STEP 2: Configure
```
Scheda Orders → Settings
Set email and success message
Save Changes
```

### STEP 3: Add to Page
```
Pages → Add New
Title: "Order Form"
Content: [scheda_clienti]
Publish
```

## 🔧 Troubleshooting

**Form not showing?**
- Clear cache
- Verify plugin active
- Check shortcode: `[scheda_clienti]`

**No email?**
- Check spam folder
- Install SMTP plugin
- Verify email in Settings

**Can't find orders?**
- Go to: Scheda Orders
- Check browser console for errors
